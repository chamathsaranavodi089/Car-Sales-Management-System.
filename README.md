# 🚗 Car Sales System

A desktop-based **Car Sales Management System** developed using Python and CustomTkinter. The application provides a graphical interface for managing car types, car details, sales, and sales records.

## 📌 About the Project

This is my final Python project for the **Advanced Python Certification course at SLIPD**.

The project was developed to apply Python programming and GUI development concepts in a practical **Car Sales Management System**. The application allows users to browse available cars, search and filter vehicles, manage car types and car details, create sales, and manage sales records.

## ✨ Features

* 🚘 View available cars in a showroom
* 🔎 Search cars by name
* 🏷️ Filter cars by car type
* ➕ Add new car types
* ✏️ Update car types
* 🗑️ Delete car types
* 🚗 Add new cars
* ✏️ Update car details
* 🗑️ Delete cars
* 🖼️ Upload and manage car images
* 🛒 Add cars to a sale
* ➕ Increase or decrease sale quantities
* 🗑️ Remove items from a sale
* 💰 Automatically calculate the total sale amount
* ✅ Complete sales
* 📋 View sales records
* 🔍 Search sales by Sale ID
* 🗑️ Delete sales records

## 🛠️ Technologies Used

* **Python**
* **CustomTkinter** – GUI development
* **Tkinter** – GUI components and dialogs
* **Pillow (PIL)** – Image processing
* **datetime** – Date management
* **os & sys** – File and system management
* **shutil** – File operations

## 💻 Desktop Application

A standalone **Windows executable (.exe)** version of the Car Sales System has also been created.

The application can be launched as a desktop application without running the Python source code directly.

### ▶️ How to Run

1. Open the `executable` folder.
2. Download `Car-Sales-System.exe`.
3. Open the `.exe` file.
4. The Car Sales System will launch as a desktop application.
